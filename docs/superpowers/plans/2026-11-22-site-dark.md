# Site Dark Visual Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle `site/` dark, with a golden-spiral hero drawn in code, a token-field band above the footer, and a matching social card and README banner.

**Architecture:**
- Colour and type tokens live once in `site/src/styles/global.css` as Tailwind theme variables, and the components use them in place of hard-coded hexes.
- The hero's frame player is replaced by an inline-SVG `Spiral.astro`.
- The token field is a pure, seeded generator (`token-field.ts`) rendered at build time by `TokenField.astro`.
- Tests read the built page and CSS, as in PR #67.

**Tech Stack:** Astro 7, Tailwind 4 (`@theme`), vitest 5, TypeScript.

**Spec:** `docs/superpowers/specs/2026-11-22-site-dark-design.md`

## Global Constraints

- Tokens:
  - page `#0C0C0B`, panel `#080808`, text `#D4CFC6`, heading `#FFFFFF`, muted `#8C877F`, rule `#2A2927`, pill `#E6E1D9`;
  - red `#E2402F`, yellow `#F4C430`, blue `#2F5BD3`.
- Path colours: answer blue, quick yellow, full red, everywhere.
- Type:
  - Newsreader 300 for headings;
  - Inter 300/400 for body;
  - JetBrains Mono, uppercase with tracking `0.1em`, for the nav, labels, buttons and captions;
  - no Plus Jakarta Sans.
- No change to copy or section order. The PR #67 page tests must keep passing.
- The primaries appear only as dots, the spiral's squares and small highlights.
- Site check: `cd site && npm run build && npm test`.

## Review Focus

1. Contrast: muted text (`#8C877F`) and dim terminal text on `#0C0C0B` meet WCAG AA (4.5:1 for body-size text).
2. Phone at 375 px: the spiral scales down with no sideways scroll, and the token field never widens the page.
3. Reduced motion: the spiral shows fully drawn, with the squares visible, and nothing animates.
4. A short laptop (1280×720): the hero copy and spiral fit above the fold without overlap.
5. Screen readers: the spiral and the token field are hidden (`aria-hidden`), so a reader doesn't spell out φ λ Σ characters.

Items 3 and 5 are pinned by tests in Tasks 2 and 4. Items 1, 2 and 4 are for the reviewer to check by hand: measured ratios, and 375 px and 1280×720 viewports.

### Task 4: The token field

**Files:**
- Create: `site/src/scripts/token-field.ts`, `site/src/scripts/token-field.test.ts`, `site/src/components/TokenField.astro`
- Modify: `site/src/layouts/Layout.astro` (render it just above the footer)
- Test: `site/src/page.test.ts`

**Interfaces:**
- Produces:
  - `type Cell = { ch: string; tone: "" | "w" | "r" | "y" | "b" }`
  - `tokenField(rows: number, cols: number, seed: number): Cell[][]`
    - Deterministic for a given seed (use a small PRNG such as mulberry32).
    - A cell is filled with probability `0.7 - 0.55 * col / cols`. Empty cells are `{ ch: " ", tone: "" }`.
    - `ch` is drawn from `"φλΣ{}→01/·∂"`.
    - Tone `"r"`, `"y"` and `"b"` each have probability 0.01 per filled cell, and `"w"` has 0.04.
- `TokenField.astro` renders `<div data-token-field aria-hidden="true">` with `tokenField(10, 190, 1618)`, one `<pre>`-style row per line. Tones map to `text-phi-red`, `text-phi-yellow`, `text-phi-blue` and `text-phi-text`, and untoned characters are `#2f2e2b`. It has `overflow: hidden` and a fixed height.

- [ ] **Step 1: Write the failing tests.**

```ts
// token-field.test.ts
const a = tokenField(10, 190, 1618), b = tokenField(10, 190, 1618);
expect(a).toEqual(b);

expect(filled(0, 40)).toBeGreaterThan(filled(150, 190) * 2);
expect(a.flat().every(c => c.ch === " " || "φλΣ{}→01/·∂".includes(c.ch))).toBe(true);

});
```
